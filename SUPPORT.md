# Support

## Supported Scope

The current release supports x86_64 Arch Linux, CachyOS, and EndeavourOS with
pacman, systemd, the default `~/.config` path, and a normal sudo-capable user.
Manjaro and other pacman systems are experimental and receive best-effort help.

Only the latest release receives installer fixes. Upstream Caelestia, Hyprland,
OpenCode, Tailscale, application, and distribution defects should be reported
to their respective projects after confirming the installer is not the cause.

## Getting Help

Use GitHub Discussions if enabled for usage questions. Use the structured bug
form for reproducible installer defects. Include the installer version,
distribution, GPU, selected profile, failing stage, and sanitized logs.

Never post secrets or private infrastructure details. Vulnerabilities and
credential exposure must follow [SECURITY.md](SECURITY.md).
